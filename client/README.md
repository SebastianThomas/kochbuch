# client

This is the frontend to my kochbuch — Vue 3, built with Vite.

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Lints files
```
npm run lint
```

### Customize configuration
See [`vite.config.js`](./vite.config.js) and the [Vite config reference](https://vite.dev/config/).
